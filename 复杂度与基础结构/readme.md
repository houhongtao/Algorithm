# 复杂度与基础结构：学习大纲

## 一、学习目标

- 理解算法效率的基本衡量方式。
- 能估算常见代码的时间复杂度与空间复杂度。
- 熟悉数组、字符串的常用操作和典型问题。
- 掌握前缀和的构造方法及适用场景。
- 能先写出正确的基础解法，再分析是否需要优化。

## 二、复杂度分析

### 2.1 为什么要分析复杂度

- 输入规模与运行时间的关系。
- 正确性、运行时间、内存使用之间的取舍。
- 根据数据规模判断朴素解法是否可行。

### 2.2 时间复杂度

- 大 O 表示法：关注增长趋势，忽略常数和低阶项。
- 常见复杂度：`O(1)`、`O(log n)`、`O(n)`、`O(n log n)`、`O(n^2)`、`O(2^n)`。
- 顺序代码：复杂度相加后保留增长最快的一项。
- 嵌套循环：分析迭代次数；循环范围不同时写出求和直觉。
- 条件分支：通常取最坏分支的复杂度。
- 二分与折半过程：每轮缩小搜索范围。
- 最好、平均、最坏情况的区别。

### 2.3 空间复杂度

- 输入空间与额外辅助空间的区别。
- 常量空间、线性空间和递归调用栈。
- 原地算法的含义及其局限。
- 用空间换时间的常见例子：缓存、哈希表、前缀数组。

### 2.4 复杂度估算练习

- 单层循环与双层循环。
- 循环变量每次乘二或除二。
- 创建长度为 `n` 的数组或哈希表。
- 递归深度与每层额外空间。
- 给定输入规模，粗略判断算法是否可行。

## 三、数组

### 3.1 基本概念

- 连续存储与按下标访问。
- 随机访问通常为 `O(1)`。
- 查找、插入、删除的成本与位置关系。
- 固定长度数组与动态数组的差别。

### 3.2 常用遍历模式

- 单次遍历与维护统计量。
- 原地修改与额外数组。
- 双层遍历及其复杂度。
- 边界处理：空数组、单元素、首尾位置。

### 3.3 典型问题

- 求最大值、最小值、总和和平均值。
- 原地反转数组。
- 删除或覆盖指定元素。
- 合并两个有序数组的基础思路。
- 暴力枚举子数组及其复杂度。

## 四、字符串

### 4.1 基本概念

- 字符序列、索引和长度。
- 字符串不可变与可变语言实现的差异。
- 字符、字节和 Unicode 字符的区别（按所用语言了解）。

### 4.2 常用操作与成本

- 遍历字符、比较字符、查找子串。
- 拼接字符串可能产生的复制成本。
- 使用字符数组或缓冲区构造结果。
- 子串截取的时间与空间成本取决于语言实现。

### 4.3 典型问题

- 判断回文。
- 统计字符频次。
- 反转字符串或单词顺序。
- 判断两个字符串是否为字母异位词。
- 简单子串匹配的暴力思路。

## 五、前缀和

### 5.1 一维前缀和

- 定义：`prefix[i]` 表示前 `i` 个元素之和。
- 构造：`prefix[i + 1] = prefix[i] + nums[i]`。
- 区间和：半开区间 `[l, r)` 的和为 `prefix[r] - prefix[l]`。
- 复杂度：预处理 `O(n)`，每次区间查询 `O(1)`，额外空间 `O(n)`。

### 5.2 适用场景

- 数组不频繁修改，但需要多次查询区间和。
- 需要快速计算子数组的和。
- 与哈希表结合，统计满足特定和的子数组数量（作为后续拓展）。

### 5.3 常见易错点

- 前缀定义使用“前 i 个元素”还是“到下标 i 为止”。
- 闭区间与半开区间的边界换算。
- 负数存在时，不能用滑动窗口替代一般的区间和查找。
- 整数溢出与空区间处理。

## 六、综合练习顺序

1. 分析几段简单代码的时间与空间复杂度。
2. 写数组遍历程序，求最值、总和和满足条件的元素数。
3. 完成数组反转、原地删除和有序数组合并。
4. 完成回文判断、字符频次统计和异位词判断。
5. 用暴力法计算多次区间和，记录复杂度。
6. 改用前缀和实现区间查询，并比较两种方案。
7. 用小规模输入手动检查空数组、单元素、负数和边界区间。

## 七、复习检查清单

- 能说清楚 `O(n)` 与 `O(n^2)` 随输入规模增长的差异。
- 能估算循环、嵌套循环、二分过程的复杂度。
- 能区分算法自身的额外空间与输入数据占用的空间。
- 能解释数组随机访问快、插入删除可能较慢的原因。
- 能指出字符串拼接在所用语言中的潜在成本。
- 能从前缀数组推导任意区间和，并正确处理边界。
- 能为每道练习写出时间复杂度、空间复杂度和至少一个边界测试。
